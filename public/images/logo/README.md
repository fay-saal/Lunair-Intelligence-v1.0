# Lunair Logo Assets Directory

Drop your logo image files into this directory (`public/images/logo/`).

### Supported formats:
- `logo.svg` (Recommended for sharp vectors)
- `logo.png` (High-res transparent PNG)
- `wordmark.png` / `wordmark.svg`
- `favicon.ico` / `icon.png`

Once uploaded, you can let me know and I will analyze the images, inspect the visual features, and integrate them into the Lunair header, hero section, and branding system!
